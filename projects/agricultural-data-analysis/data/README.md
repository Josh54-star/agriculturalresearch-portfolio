# Data

This folder contains data used by the analytical workflow.

The initial portfolio workflow uses a **synthetic demonstration dataset** generated by `R/01_generate_demo_data.R`. It is deliberately labelled as synthetic so that no fabricated empirical finding is presented as real agricultural evidence.

The workflow is designed so the synthetic dataset can later be replaced with a documented public agricultural dataset without changing the core analytical structure.

## Intended public-data source

FAOSTAT provides free food and agriculture statistics for more than 245 countries and territories. Its crop production dataset contains annual harvested area, production and yield measures at national and global levels. The current catalogue describes coverage through 2024 and provides the data under CC BY 4.0. See the project README for source documentation.
