# Impact Evaluation of an Agricultural or Development Intervention

## Portfolio project

### Overview

This project will demonstrate how I approach causal questions in agricultural and development research.

The central objective is to estimate whether an intervention is associated with a measurable change in an outcome while explicitly considering the assumptions required for causal interpretation.

### Evaluation framework

The project will use a publicly available longitudinal or repeated cross-sectional dataset suitable for an impact-evaluation design.

A Difference-in-Differences (DiD) framework will be considered where treatment and comparison groups can be observed before and after an intervention.

### Core workflow

1. Define the intervention and causal estimand
2. Identify treatment and comparison groups
3. Inspect pre-intervention trends
4. Clean and construct analytical variables
5. Estimate the baseline DiD specification
6. Conduct specification and robustness checks
7. Visualize treatment and comparison trends
8. Interpret the estimated effect and limitations

### Methods

- Difference-in-Differences
- Regression modelling
- Fixed effects where appropriate
- Clustered standard errors where justified
- Pre-trend assessment
- Robustness and sensitivity analysis

### Tools

R / Stata / Python

### Reproducibility standard

The completed project will contain:

- Data-source documentation
- Analysis scripts
- Variable construction notes
- Model specifications
- Tables and figures
- Interpretation of findings
- Limitations and identification assumptions

Raw restricted data will not be committed to GitHub.
